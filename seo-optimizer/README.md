# GSC daily content analysis

Ця система щодня аналізує фіналізовані дані Google Search Console, але **сама не переписує і не публікує статті**.

## Щоденний цикл

1. GitHub Actions запускає аналіз щодня.
2. Беруться 28 днів GSC проти попередніх 28 днів, а також останні 7 завершених днів проти попередніх 7.
3. Аналізуються тільки актуальні article URL, які реально є в sitemap.
4. Для кожної сторінки збираються clicks, impressions, CTR, average position і топові пошукові запити.
5. Система визначає сильні сторінки та слабкі opportunity-кандидати з урахуванням CTR сторінок на близьких позиціях і негативного тренду.
6. Результат зберігається як GitHub Actions artifact `latest-report.json` + `latest-report.md`.

Коли користувач питає «що вийшло», ChatGPT читає найновіший щоденний звіт і пояснює, що заходить добре, що відстає і чому.

## Команда «Переробка»

Тільки після слова **«Переробка»** ChatGPT бере останній завершений GSC-звіт, читає production і актуальний GitHub main, порівнює слабкі статті з найсильнішими та переробляє до 10 статей за один день.

Переробка відбувається в окремій branch/PR. Автоматичного merge немає. Slug не змінюється без окремої SEO-причини. Після merge перевіряються production, SSR, canonical, indexability, internal links і sitemap.

Ціль кампанії — **10 статей на день протягом 24 днів**, тобто до 240 статей. `history.json` використовується як журнал уже пройдених переробок, щоб у межах кампанії не брати одну й ту саму статтю замість ще не опрацьованої.

Важливе обмеження: якщо Search Console ще не має достатньо даних по сторінці, система не називає її «поганою» лише заради заповнення десятки. Такі сторінки залишаються в `insufficientData` і можуть бути перевірені пізніше за накопиченими даними.

## GitHub Secrets

Потрібні лише:

- `GSC_SITE_URL` — точна property Search Console (`sc-domain:...` або URL-prefix);
- `GSC_SERVICE_ACCOUNT_JSON` — JSON service account із read access до property.

OpenAI API key для щоденного workflow більше не потрібен: інтелектуальний аналіз і реальна переробка виконуються через ChatGPT після команди користувача.
