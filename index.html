FAQ

Коротко про сайт

Для кого цей сайт?

Для людей різного віку, які стикаються з відкладанням, відсутністю мотивації, втратою інтересу, виснаженням або труднощами зі стартом.

Чому лише 12 основних тем?

Щоб не створювати десятки майже однакових сторінок. Кожна тема має охоплювати окремий великий поведінковий механізм або життєву проблему.

Чи буде тест для підбору статті?

Так. Для великих підрозділів планується короткий тест, який допоможе підібрати найближчу до ситуації тему. Людина також зможе обрати матеріал самостійно.

Чи встановлює сайт діагнози?

Ні. Матеріали призначені для самоосвіти й не замінюють консультацію лікаря або психолога.
